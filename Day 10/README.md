# 🚀 My JavaScript Projects

This repository contains two beginner-friendly JavaScript projects developed to practice programming fundamentals and improve problem-solving skills.

## 🎮 1. Number Guessing Game

A simple number guessing game where the player has to guess a randomly generated number between **1 and 10**.

**Features:**
- Generates a random number between 1 and 10.
- Allows users to enter their guesses.
- Checks whether the guessed number is correct.
- Provides feedback to help the player.

**Repository:**  
[Number Guessing Game](https://github.com/JaniduSathsara/Number-Guessing-Game)

---

## 📝 2. To-Do Application

A simple To-Do application that helps users manage their daily tasks efficiently.

**Features:**
- Add new daily tasks.
- Update existing tasks.
- Delete completed or unwanted tasks.
- Manage daily activities easily.

**Repository:**  
[To-Do Application](https://github.com/JaniduSathsara/To-Do-Application)
